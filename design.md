# Design

Same system as Shipped (`../shipped/design.md`): Inter Tight + Instrument Serif italic accents + JetBrains Mono labels, near-black tones, rounded media tiles, mono status chips, RemotoLabs lockup.

Product accent: **electric orange `#ff6a3d`** (Shipped is lime `#d8ff85`), so RemotoLabs products read as one family with one colour each. Change it in `src/styles/global.css` (`--color-spark`).

Structure follows DesignJoy: hero → how it works (+ request board mock) → membership benefits → recent work → scope → comparison → testimonials → pricing (+ guarantees) → Calendly intro call → FAQ → closing CTA.

Imagery rules: device mockups always fully visible in their frame; real work in `public/work/`, stand-ins in `public/placeholder/`.
